## Connected workflows

Create branches and subscribers, record cash, upload and review proofs, configure QR images, log expenses, export a ledger, assign tickets, save internal notes, publish alerts, activate subscribers, and review installation applications. Records stay in this browser and synchronize across tabs on the same site.

## Awaiting connection

- Sign-in, permission enforcement, invitation and recovery emails, password changes, and real device-session revocation.
- Shared online records, permanent file storage, and production billing schedules.
- Real AI calls and measured token usage. Summaries and suggestions currently use templates.
- Device push and automatic reminder delivery. Notification preferences and in-app previews are available.
- Router monitoring and bandwidth updates. Usage values are saved sample readings.

## Payment and credential information

No money is transferred inside JMWired. A proof must be checked against the transfer in the provider's collection account. Use fictional account numbers and sample images while exploring.

Passwords and API key values are discarded. AI setup saves only a configured status. Use placeholders in credential fields.

## Storage and resetting

**Restore sample data** clears changes and uploaded images. If browser storage fills, changes remain only for the current session. Image uploads accept PNG, JPEG, or WebP up to 1 MB.

Monthly totals use the preview's saved subscriber records, not historical accounting snapshots. Production billing will preserve each month's bill amount and subscriber state.
