---
title: "Platform administration"
description: "Manage organizations and global access."
---

Open **Platform admin** from your profile dropdown. [Super admin](http://127.0.0.1:3001/admin) is separate from branch navigation.

The overview shows organization, customer, active connection, and user counts. **Open workspace** enters a branch. **Create organization** creates a service area. User roles can be **User** or **Platform admin**; the current owner cannot be demoted here.
