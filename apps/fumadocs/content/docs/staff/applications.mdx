---
title: "Review installation requests"
description: "Turn an application into a subscriber record."
---

Share **Installation requests → Open application form** with households who want service. It collects name, phone, optional email, address, preferred plan, notes, and consent to be contacted.

1. Open a new request with **Review request**.
2. Check coverage and contact the applicant.
3. **Mark contacted**, **Decline**, or **Approve & create subscriber**.
4. Approval creates one **Pending installation** subscriber.
5. **View subscriber** to add installation notes and update the connection when work is complete.

Request states are **New**, **Contacted**, **Approved**, and **Declined**. Platform maintenance and registration controls can pause the public application form.
